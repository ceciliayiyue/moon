# Moon Memories

Interactive moon artwork built with Next.js App Router, React, TypeScript, and Tailwind CSS.

## How to run

```bash
npm install
npm run dev
```

Then open the local URL printed by Next.js, usually `http://localhost:3000`.

## What it includes

- Full-screen moon background image
- Interactive moon doodles rendered from the Google Quick, Draw! dataset
- Mouse movement, click, and zoom interactions
- A lightweight local API route that proxies the moon doodle dataset

## Folder structure

```text
app/
  api/moon/route.ts
  globals.css
  layout.tsx
  page.tsx
public/
  moon-bg.jpg
```
